///  Calculadora Android ///


Proyecto realizado en Android Studio.


------- Funcionalidades -------
  * Suma
  * Resta
  * Multiplicación
  * División
  * Memoria (M+, M-, MR, MC)
  * Porcentajes
  * Cambio de signo (±)
  * Borrado de caracteres (←)
  * Números decimales
  * Control de división entre cero
  * Reproducción de vídeo al pulsar "="


------ Tecnologías ------
  * Java
  * Android Studio
  * XML
